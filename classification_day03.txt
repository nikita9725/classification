<b>День 3 — Baseline модель классификации</b>

🎯 <b>Цель дня</b>
Построить первую рабочую baseline-модель, от которой дальше можно улучшать качество.

📋 <b>Задачи</b>
1. 🧬 Выбрать baseline vectorization, например TF-IDF
2. ✂️ Разделить данные на train/test
3. 🎯 Обучить baseline-модель, например Logistic Regression
4. 📏 Посчитать ключевые метрики качества
5. 💾 Сохранить baseline результаты
6. 📝 Зафиксировать baseline как точку отсчёта

<b>🎉 Критерии успеха</b>
- ✅ Есть baseline pipeline
- ✅ Модель обучается и делает предсказания
- ✅ Есть метрики на test set
- ✅ Baseline результат сохранён для сравнения
