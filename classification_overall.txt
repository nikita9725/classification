<b>Комплексное задание: Классификация текстов как ML mini-product</b>

🎯 <b>Цель проекта</b> — разработать прикладную систему классификации текстов, которая умеет загружать датасет, проводить предобработку, обучать baseline-модель, улучшать качество, анализировать ошибки и делать предсказания на новых данных. Проект должен быть реализован как единый ML workflow, а не как набор отдельных экспериментов.

Проект состоит из 7 этапов, соответствующих 7 дням разработки, и финальной интеграции.

📋 <b>Общая концепция проекта</b>

Вы разрабатываете учебный classification pipeline, который умеет:
- 📥 загружать и проверять датасет
- 🧹 очищать и подготавливать тексты
- 🧬 превращать тексты в признаки
- 🎯 обучать baseline-модель
- 📈 сравнивать несколько улучшений
- 🔍 анализировать ошибки модели
- 💬 делать предсказания на новых текстах

<b>Важно по scope:</b>
Это учебный <i>single-task mini-product</i>, а не соревнование по SOTA-качеству. Цель — пройти полный цикл text classification проекта: data → preprocessing → baseline → improvement → evaluation → inference.

🏗️ <b>Ключевые концепции</b>
В проекте должны учитываться:
- 🧹 preprocessing текста
- 🧬 vectorization
- 🎯 supervised classification
- 📏 evaluation metrics
- 📊 comparison of approaches
- 🔍 error analysis
- 💾 сохранение модели и inference

## 🛠️ Технологический стек

- <b>Python</b> — основной язык
- <b>pandas</b> — работа с данными
- <b>scikit-learn</b> — baseline модели и метрики
- <b>matplotlib</b> / <b>seaborn</b> — визуализация
- <b>joblib</b> — сохранение модели
- <b>Jupyter Notebook</b> или Python scripts — по желанию

## 📋 Общие требования

1. 📥 Должен использоваться датасет с текстами и метками классов
2. 🧹 Должен быть этап предобработки текста
3. 🎯 Должна быть baseline-модель
4. 📈 Должны быть минимум 2–3 попытки улучшения baseline
5. 📏 Качество должно оцениваться понятными метриками
6. 🔍 Должен быть error analysis
7. 💬 Должен быть финальный inference pipeline для новых текстов

## 🎉 Критерии успешного завершения

К концу 7 дней система должна уметь:
- 📥 загружать датасет
- 🧹 очищать тексты
- 🧬 строить признаки
- 🎯 обучать и сохранять модель
- 📈 сравнивать несколько подходов
- 🔍 анализировать ошибки
- 💬 делать предсказание на новых примерах
